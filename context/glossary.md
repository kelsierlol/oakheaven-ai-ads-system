# Glossary — Oakhaven Media

## Product / Offer Terms

| Term | Meaning |
|------|---------|
| Content Immersion System | The unique mechanism. Three-phase process: Brand Download → Contextual Editing → Quality Gate. *Note: the client's dump also calls it the "Content Immersion Method" — pick one name and lock it. Default to "System."* |
| Brand Download | Phase 1. Structured deep-dive into the client's business, audience, competitors, content style and reference videos, completed before any editing starts. |
| Contextual Editing | Phase 2. Matching every graphic, b-roll clip and text overlay to the specific point being made at that specific moment, rather than dropping in generic stock. |
| Quality Gate | Phase 3. The project manager reviews every edit against the Brand Download profile before it reaches the client — style match, b-roll relevance, typos, pacing. |
| Project Manager / Creative Manager | The second person on every account. *Two names for one role in the client's dump — pick one. "Creative manager" reads better for the quality claim; "project manager" reads better for the reliability claim.* |
| Custom graphics | Purpose-built visuals for the specific point being made. The contrast term to "generic b-roll" / stock footage. |
| Hook bot | The free AI tool included with orders that generates viral hooks. **[GAP]** — name, access method, whether it's actually live. |
| Free video edit | The lead magnet on the primary CTA: book a 15-minute call, get one video edited free. |

## Customer Terms

| Term | Meaning |
|------|---------|
| Coaches | Coaches/consultants selling a program or service, using content as the acquisition channel. The premium-positioning (TOF) target. |
| Business owners | Service business owners self-filming for marketing. The time-pain target — largest segment in competitor ads. |
| Creators | Content creators blocked at the editing step. Lowest budget confidence of the segments. |
| Burned / been burned | Prospect who has already paid a freelancer or agency and got ghosted or got generic work. The dominant emotional state in this market. |
| Ghosting | A freelancer disappearing mid-project or after payment. Enemy vocabulary — use it, the market uses it. |
| Back-and-forth | The revision loop: re-explaining the brief, flagging typos, fixing wrong footage. What the Quality Gate is sold against. |
| Generic edit | An edit that is technically competent but disconnected from what the client actually meant. The core problem the mechanism claims to solve. |

## Ad / Performance Terms

| Term | Meaning |
|------|---------|

| ROAS | Return on Ad Spend |
| CPM | Cost Per 1,000 Impressions |
| CPC | Cost Per Click |
| CTR | Click-Through Rate |
| CR | Conversion Rate |
| Hook Rate | 3-second video views / impressions |
| Hold Rate | ThruPlay / 3-second views |
| WC | Winning Concept |
| HO | Hook Variation |
| TOF | Top of funnel — the premium-positioning angles |
| BOF | Bottom of funnel — the pain-led angles (quality, back-and-forth, storytelling, being scrolled past) |
