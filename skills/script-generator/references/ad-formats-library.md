# Ad Formats Library — Reference File

Reference file for the Ad Script & Storyboard Generator. When a format is assigned from the creative strategy map, pull the specs from this file. These define the structural container — scene count, word count, pacing, recording setup, and editing style.

**Note:** This file will be updated as new formats are tested and validated. If a format is not listed here, flag it in the script output and define specs based on the closest match.

---

## Video Formats

### UGC Selfie / Founder Ad

| Spec | Target |
|------|--------|
| Duration | 60-120 seconds |
| Word Count | 120-200 words |
| Scene Count | 4-6 scenes |
| Recording Setup | Selfie camera, handheld or propped. Natural lighting. Casual setting (home office, kitchen, car, walking). NO studio. |
| Pacing | Conversational. Feels like a voice note to a friend. Natural pauses. No rushing. |
| Editing Style | Minimal cuts. Captions on (large, readable). Light background music. Jump cuts only to remove dead air, not for style. B-roll inserts for proof moments (screenshots, product shots). |
| Sentence Length | Max 15 words per sentence. Must be readable in one breath without a teleprompter. |

**Best for:** Problem-Aware and Solution-Aware audiences. Personal, relatable. Works well with Transformation, Relatable Moment, and Identity hooks.

---

### Talking Head (Authority)

| Spec | Target |
|------|--------|
| Duration | 90-180 seconds |
| Word Count | 180-300 words |
| Scene Count | 6-10 scenes |
| Recording Setup | Front-facing camera at eye level. Clean background (bookshelf, whiteboard, branded wall). Ring light or key light. Lav mic or shotgun mic. |
| Pacing | Confident, measured. Slower than UGC. Pauses for emphasis. Educational tone, not salesy. |
| Editing Style | Clean cuts between points. Text overlays for key stats/numbers. Lower thirds for credibility (name, title). B-roll inserts for examples. Captions on. |
| Sentence Length | Max 20 words per sentence. Slightly more complex than UGC — the authority tone can support it. |

**Best for:** Solution-Aware and Product-Aware audiences. Credibility-heavy. Works well with Proof Lead, Misconception, and Contrarian hooks.

### B-Roll + Read Caption

| Spec | Target |
|------|--------|
| Duration | 30-60 seconds |
| Word Count | 60-120 words |
| Scene Count | 5-8 scenes (fast cuts) |
| Recording Setup | No on-camera talent. B-roll footage only — product shots, lifestyle, process, results. |
| Pacing | Fast. 2-4 seconds per scene. Driven by the editing rhythm, not a speaker. |
| Editing Style | Captions are the primary content delivery — large, bold, animated. Punchy music. Fast transitions. Each scene is a visual beat that reinforces the caption. Trending audio optional for Reels/TikTok. |
| Sentence Length | Max 10 words per caption line. Punchy. Fragments are fine. |

**Best for:** Unaware and Problem-Aware audiences. High scroll-stop rate. Works well with Symptom, Pattern Interrupt, and Catalyst hooks.

---

### Notepad / Text-on-Screen

| Spec | Target |
|------|--------|
| Duration | 30-60 seconds |
| Word Count | 50-100 words |
| Scene Count | 1-3 visual scenes (text builds on screen) |
| Recording Setup | Screen recording of Notes app, Google Doc, whiteboard, or simple text animation. |
| Pacing | Text appears line by line. Reader follows along. Slightly slower than B-Roll. |
| Editing Style | Clean text animation. Each new line is a new beat. Optional voiceover reading the text. Subtle background music. No flashy transitions. |
| Sentence Length | Max 12 words per line. Short, direct. Each line is a standalone thought. |

**Best for:** Any awareness level. Low-production, high-authenticity feel. Works well with Missed Step, Misconception, and Contrarian hooks.

### Testimonial / Case Study

| Spec | Target |
|------|--------|
| Duration | 60-120 seconds |
| Word Count | 120-200 words |
| Scene Count | 4-6 scenes |
| Recording Setup | Real customer on camera (selfie or interview setup). Authentic environment. NOT a studio testimonial. |
| Pacing | Natural speech. Unscripted feel even if loosely scripted. Emotional beats allowed to breathe. |
| Editing Style | Minimal. Let the person talk. Overlay key stats as text. Cut to B-roll or screenshots for proof moments. Captions on. |
| Sentence Length | N/A — this is meant to sound unscripted. Provide talking points, not a word-for-word script. |

**Testimonial structure (6 parts):**
1. Their situation before (matches prospect's current state)
2. What triggered them to try this (relatable catalyst)
3. How they discovered it (recommendation or social proof)
4. One minor limitation (builds credibility)
5. The primary benefit / transformation
6. Recommendation + secondary benefit ("even my [person] noticed...")

**Best for:** Product-Aware and Most Aware audiences. Proof-heavy. Works well with Proof Lead and Transformation hooks.

### Testimonial Compilation

| Spec | Target |
|------|--------|
| Duration | 60-90 seconds |
| Word Count | N/A (multiple speakers) |
| Scene Count | 8-12 clips (3-8 seconds each) |
| Recording Setup | Mixed — selfie clips from multiple customers. Different people, different settings, different looks. |
| Pacing | Fast — each person delivers one key line, then cut to the next. Builds momentum. |
| Editing Style | Hard cuts between people. Consistent caption style across all clips. Build from smaller wins to bigger wins. End on the strongest testimonial. |
| Sentence Length | One key sentence per person. 5-12 words each. |

**Best for:** Product-Aware audiences. Volume of proof. Works well with Proof Lead hooks.

---

### Educational Explainer

| Spec | Target |
|------|--------|
| Duration | 90-180 seconds |
| Word Count | 200-350 words |
| Scene Count | 8-12 scenes |
| Recording Setup | Talking head + heavy B-roll / diagram overlays. Think "mini-documentary" or "YouTube explainer." |
| Pacing | Steady educational pace. Not rushed. Each point lands before moving to the next. |
| Editing Style | Diagrams, charts, visual metaphors overlaid on talking head. Text callouts for key terms. Chapter-style scene transitions optional. Captions on. |
| Sentence Length | Max 20 words. Clarity over brevity — the audience is in learning mode. |

**Best for:** Unaware audiences (education-first structure). Also strong for Problem-Aware with the full DR framework. Works well with Misconception, Symptom, and Catalyst hooks.

---

### Reaction Video

| Spec | Target |
|------|--------|
| Duration | 30-90 seconds |
| Word Count | 80-150 words |
| Scene Count | 3-6 scenes |
| Recording Setup | Split-screen or picture-in-picture. Reactor on camera watching/reacting to content (competitor ad, customer result, before/after, data). |
| Pacing | Driven by the reaction. Natural surprise, commentary, breakdown. |
| Editing Style | PIP or split screen. Highlight key moments. Reactor's facial expressions carry the emotion. Captions on. |
| Sentence Length | Max 15 words. Conversational reactions, not scripted commentary. |

**Best for:** Solution-Aware audiences. Differentiation play. Works well with Contrarian and Proof Lead hooks.

---

### Story-Style (45-60 Second)

| Spec | Target |
|------|--------|
| Duration | 45-60 seconds |
| Word Count | 90-130 words |
| Scene Count | 4-5 scenes |
| Recording Setup | UGC or talking head. Personal, intimate. |
| Pacing | Narrative arc: tension → discovery → resolution. Slightly faster than full UGC. |
| Editing Style | Minimal cuts. One continuous narrative. Captions on. B-roll inserts for proof only. |
| Sentence Length | Max 15 words. |

**Structure:** Hook (Problem) → Agitation → Solution Discovery → End Result → CTA

**Best for:** Problem-Aware audiences. Quick story that builds empathy and resolves with the offer. Works well with Relatable Moment and Transformation hooks.

## Static Formats

### Static Image (Single)

| Spec | Target |
|------|--------|
| Text | Max 125 characters primary text. Max 40 characters headline. |
| Visual | One hero image. Product, lifestyle, or proof-based. |
| Layout | Image carries 80% of the message. Text reinforces, doesn't replace. |

**Best for:** Most Aware audiences (direct offer), or Unaware audiences (symptom-based imagery that stops the scroll).

---

### Carousel

| Spec | Target |
|------|--------|
| Slides | 3-6 slides |
| Text per slide | Max 30 words per slide |
| Pacing | Each slide is one beat of the argument. Slide 1 = hook. Last slide = CTA. |
| Visual | Consistent visual style across all slides. Each slide is a standalone point that builds on the previous. |

**Best for:** Solution-Aware audiences. Comparison plays, proof stacks, step-by-step explainers. Works well with Missed Step and Misconception hooks.
