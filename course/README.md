# The AI Ads Operator Course

Build your own AI ads system by running our client onboarding flow on your own business. By the end, you'll have a fully loaded, working system and you'll know how to run the same process for your clients.

---

## The Fast Path (What Most People Should Do)

**Steps 01 → 05.** Total time: 3-4 hours + however long it takes to gather your pre-flight assets.

1. **Step 01** — The Mental Model (5 min)
2. **Step 02** — Install Claude Code (10 min)
3. **Step 03** — Load Your Workspace (10 min)
4. **Step 04** — Asset Inventory: Pre-Flight Checklist (30 min + gather time)
5. **Step 05** — Use The Master Setup Prompt (2–3 hours inside Claude)

Step 04 is critical. It ensures you have every asset the system needs BEFORE you paste the Master Setup Prompt. Skip it and your outputs will be generic.

---

## The Deep Dive Path (Optional)

Steps **06–15** explain in detail what Claude does during each phase of the Master Setup. Read these if you want to:

- Understand the system at a deeper level
- Run this process for your clients (not just yourself)
- Re-run a specific phase manually later (e.g., Creative Strategy with new data)
- Build your own custom skills more effectively

**Not required for your own setup.** Skip them if you just want to get operational.
